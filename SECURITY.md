# Security Policy

## Scope

This repository is maintained as a software project or research artifact. Please do not test against systems, accounts, networks, or data that you do not own or have explicit written authorization to assess.

## Reporting a vulnerability

Please open a private security report through GitHub’s **Security** tab when that feature is available. If private reporting is unavailable, open a minimal public issue without exploit details and request a private contact channel. Do not publish credentials, personal data, or weaponized proof-of-concept material.

## Responsible use

Security-sensitive functionality is intended for authorized testing, controlled laboratories, education, and defensive engineering. Users are responsible for complying with applicable law and obtaining permission before use.

## Disclosure

Reports will be reviewed in good faith. Please allow reasonable time for validation and remediation before public disclosure.
